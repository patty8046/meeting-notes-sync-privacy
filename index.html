Meeting Notes Sync

Meeting Notes Sync is a private tool used by one person, its owner. It copies the owner's own meeting summaries and transcripts into Google Docs in the owner's own Google Drive and sorts them into project folders.

It is not offered to anyone else and has no other users.

It asks Google for a single permission (drive.file). That permission only lets it create files and folders and edit the files it created itself. It cannot see or change any other file in Google Drive.

Privacy policy

Meeting Notes Sync. Effective 7 October 2026.

Who uses it

Meeting Notes Sync is used only by its owner. It has no other users and does not collect data about anyone who visits this page.

Google data it accesses

The tool uses the Google Drive scope drive.file. With it, the tool creates folders and Google Docs in the owner's Drive and edits only those files. It cannot read, list or change any other file.

What it does with that data

  • It writes the owner's meeting summaries and transcripts into the documents it created.
  • It reads back only those documents, to avoid duplicates and to fill in transcripts later.
  • It does not sell, share, transfer or disclose Google user data to anyone.
  • It does not use Google user data for advertising or to train AI models.

Storage

The Google sign-in token is stored only on the owner's own computer. There is no server and no database operated by the tool.

Google API Services User Data Policy

Meeting Notes Sync's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
